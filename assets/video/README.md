# مجلد الفيديوهات

هذا المكان المخصص لفيديوهات الموقع (مثل فيديو الهيرو للرياض المذكور في `docs/content.md`).

## قبل رفع أي فيديو هنا
- الصيغة: MP4 (H.264) كخيار أساسي، ويفضل نسخة WebM إضافية لحجم أصغر.
- الحجم: يفضّل ضغط الفيديو وتصغير حجمه قبل الرفع حتى لا يبطئ تحميل الصفحة.
- التسمية: اسم واضح بالإنجليزية وبحروف صغيرة، مثل `hero-riyadh.mp4`.
- لكل فيديو أضف نص بديل مناسب أو عنوان `<track>` إن كان فيه حوار، لدعم SEO وسهولة الوصول.
